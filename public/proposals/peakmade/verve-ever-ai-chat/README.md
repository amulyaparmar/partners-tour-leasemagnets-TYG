## Content boundaries

The page is a sales proposal, not an installed chat service. Its eight conversations are scripted, labeled examples. It collects no data and sends no messages. Current rates and availability are referred to each property's live leasing sources. No invented pricing, metrics, guarantees, discounts, commitments or integration capabilities are included. Opening and amenity information describes the websites' advertised plans, not completed construction. Do not transplant unrelated production-package pricing into this AI Chat version.

All files for this version live in this directory. No global styles, dependencies, routing or existing pages need modification.
